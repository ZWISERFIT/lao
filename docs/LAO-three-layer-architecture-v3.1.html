LAO — Logically Anchored Ontology

三层架构终版 · 完整通用组件 · 开源 Apache-2.0 · LAO 与 ZWISERFIT-OS 拆分后
包名: lao-human-calibration v0.2.0-beta  |  License: Apache-2.0  |  定位: 让 Agent 不再忘事、不再胡说，像人一样记住真实经验并自动复利。
结构: 三层（L1 路由决策 / L2 经验工厂 / L3 确权交易）· 用户下载的完整通用组件

一、架构总览

LAO 是 Agent 的人性校准层 + 可靠性框架，由三层组成，用户下载的是完整组件：

层职责核心模块
L1 路由决策模型智能选择 + 降级 + 成本追踪routing/
L2 经验工厂真实经验沉淀 → 可复用可验证锚点（含行为引擎内核）effect_anchored/ + core/
L3 确权交易经验产权、估值与安全交换边界contract / evaluator / consent / readiness
关于"五引擎"：五引擎（认知/经验/路由/演化/优化）是 L2 经验工厂内的能力维度，不是独立架构层。创始人的三层是架构分层，两者是同一事实的不同表述。

二、L1 · 路由决策

根据任务分类选择最优模型，构建跨 provider 降级链路，杜绝 400 模型-端点不匹配。

模块职责
routing/model_router.py模型路由与降级链路（三层 provider 故障转移）
routing/task_classifier.py功耗感知式任务分类
routing/task_decomposer.py复杂指令拆解 · 多模型组合路由
routing/agent_reliability.pyAgent 可靠性评分引擎
routing/cost_tracker.py路由调用成本日志（远程成本汇·可配置）
routing/timeout_matrix.py · switch_audit.py超时矩阵 · 切换审计
✅ 已泛化脱敏：LAO 通用版中 provider 使用 provider_a / provider_b / provider_c 通用标识，成本同步用 Remote cost sink（可配置 URL）——不含任何 ZWISERFIT-OS 专有命名。ZWISERFIT-OS 内部部署版保留真实引用。

把真实经验沉淀为可复用、可验证的认知锚点，包含行为引擎内核（李人性层）。分四个能力块：

模块职责

evolution/atom_engine.pyTrust Event→Atom→Anchor 经验复利闭环

3.2 经验验证

四、L3 · 确权交易

经验的产权、估值与安全交换边界——确权机制属 LAO 通用组件（开源），交易市场实现归 ZWISERFIT-OS（闭源）。

模块职责归属
experience_contract.py经验共享安全契约 · 跨域污染保护✅ LAO（开源）
ethan/experience_evaluator.pyEthan 三维评估（QS 认证）· 经验估值基础✅ LAO（开源）
consent_gate.py · consent_integration.py用户同意门 · 运行时同意集成✅ LAO（开源）
experience_readiness.py经验就绪度追踪✅ LAO（开源）
experience_graph.py / matching图谱匹配 · 通用能力✅ LAO（开源）
melody_interface.py / melody_builder/积木式 Agent 组合与交易市场（DID/水印/定价/社群）❌ ZWISERFIT-OS（闭源 Melody）
✅ 边界明确：LAO = 确权机制（契约+评估+同意+就绪度），开源通用。Melody = 交易市场（定价阶梯 + DID 确权 + 哈希水印 + 社群），闭源归 ZWISERFIT-OS。LAO 只存契约/锚点/验证，不做身份/偏好/匹配的商用实现。

五、数据模型与集成

  • lao/schema.py：Trust Event 与 VerifyPing 数据模型（贯穿全链路存证）
  • erge_writer.py：三层认知锚点 → SQLite（ERGE）五表联动持久化
  • cli.py / init.py：pip install lao-human-calibration → from lao import LAOAgent; agent=LAOAgent(); agent.run()
  • dashboard/gen_dashboard.py：LAO 可靠性仪表盘 HTML 生成
  • validation/skill_validator.py：技能/能力边界校验
