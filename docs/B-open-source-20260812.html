你拿到的是开放协议，不是黑盒

LAO 开放这些，欢迎接入 + 替换 + 验证：

RoutingProtocol 路由契约 TaskClassifier 任务分类 CostTracker 成本追踪 SwitchAudit 切换审计 CognitivePolicy 认知策略注入 FeedbackBus 反馈总线 ExperienceContract 经验契约 Consent 授权门 Attestation 经验证明 TrustEvent 信任事件 Ownership 产权确权 Melody 市场协议

这些是接口/协议/结构——协议全部开放，你的 Agent 可以接入、理解、验证，甚至替换其中任意一环。

可信验证能力（向所有人开放）

LAO 的核心承诺——错误不会降低信任，隐藏错误才降低信任。

  • Trust Event Ledger — 所有行为/错误/修正，可验证的信任账本
  • Attestation — 经验可被独立验证真实性与归属
  • Hash + Verification — 隐私友好，验证明文不暴露原始数据
  • 审计链 — Agent 决策链可被独立验证，无人能篡改

接入 LAO（快速开始）

from lao import LAOAgent

agent = LAOAgent()
# 观察行为 → 沉淀经验 → 构建约束
agent.watch(user_id="u1", behavior_text="用户今天完成了3组深蹲")
agent.add_constraint("价格超$99不推荐", trigger="预算", level="yellow")
# 你的 Agent 从此记住、可信、可约束
