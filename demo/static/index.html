H — Hallucination Gate

deterministic

Validates LLM output against schema, fact, and rule constraints — all outside the LLM's probability space.

gate = HallucinationGate(
  constraints_path="rules/medical.json",
  anchors_path="facts/db.json"
)
result = gate.check(llm_output, context)
⚓

M — Memory Anchor

deterministic

Deterministic key-value retrieval. No semantic search, no probabilistic fallback — exact match or honest "I don't know".

mem = MemoryAnchor(anchor_db_path="facts/db.json")
result = mem.lookup("founder_first_store_location")
# → MResult(found=True, value="东莞市万江街道")
🔗

C — Context Rebuilder

deterministic

Record structured events with content hashes. After session compaction, rebuild the full event chain.

recon = ContextRebuilder(session_id="demo")
recon.record(Event(
  event_id="evt_1", speaker="founder",
  event_type="decision", subject="Strategy",
  summary="...", content_hash="abc123"
))
📊

E — Effect Anchoring

deterministic

Trust scoring from observed effects. "DeepSeek claims streaming works" → "We observed 5 successes, 1 timeout over 6 trials".

effect = EffectAnchoring(min_observations=3)
effect.record(CapabilityObservation(
  capability="streaming", provider="deepseek",
  model="v4-pro", success=True, latency_ms=3200
))
🧬

A — Adaptive Constraint

LLM-assisted

One violation → equivalence class → rule → all future violations blocked. Compound interest on errors.

adaptive = AdaptiveConstraint()
v = Violation(
  violation_id="v_001", layer="fact",
  description="Agent suggested squats for knee pain"
)
rule = adaptive.derive(v)
🔍

S — Self Audit

meta-audit

Meta-audit of the rule system. H checks agent output against rules. S checks if the rules themselves are correct.

audit = SelfAudit(staleness_days=30)
report = audit.audit(
  rules=rules, rule_stats=stats,
  violation_patterns=gaps
)
