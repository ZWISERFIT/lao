# LAO Trust Casebook

> **原则：** 错误不会降低信任，隐藏错误才降低信任。
> **它证明什么：** LAO 不是"不犯错的 Agent"，而是"从每个错误中学习的 Agent"。

## 打开账本

→ [完整 Trust Event Ledger](./ledger-v1.json)（机器可读 · 9 个事件 · 持续追加）

## 这里记录了什么

每个 Trust Event 都是一条**真实发生过**的错误或成功：发生了什么 → 证据 → 如何修复 → 固化成了什么不可绕过的机制（Anchor）。

**精选案例：**

| 事件 | 发生了什么 | 修复成什么机制 |
|:--|:--|:--|
| E-LUNA-008 | Agent 报"无法读图"，但读图技能一直可用——缺的是"先查技能库"的认知路径 | **C005 能力探测 Gate**：报"不会"前强制检索技能库 ≥3 次 |
| E-SHUYU-003 | HTML 审阅 URL 两次用错端口（8443）——"知道"≠"执行时正确" | **A-OUTPUT-004**：端口强制锁定 8444 |
| E-SHUYU-005 | C005-2 仍犯同模式错误——纸面规则拦不住 | **C005-2 URL 交付三重校验门**：格式+文件+HTTP 三硬检查 |
| S-LAO-001 | 记忆压缩引擎成功——上下文精简不丢关键 | Token Compression Engine |

## 为什么这对你有价值

传统 "agents that never fail" 是谎言。真实世界是 **"agents that learn from every failure"**。

LAO 把每一次错误变成组织的免疫力：**错误不再重演，因为你把它铸成了不可绕过的门。** 这正是 LAO 装到 Agent 上之后，你拿到的核心价值——不是"不会错"，是"错了就能学到永不重犯"。
